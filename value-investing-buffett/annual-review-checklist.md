# Annual Portfolio Review Checklist

> **"Review each holding as if you were considering buying it for the first time. Don't overlook its flaws just because you already own it."**
> — Buffett's implicit logic

## How to Use

At least once per year (suggested: year-end or after Berkshire's annual report release), conduct a complete review of each holding.

**Core principle: Zero-based thinking** — If you held cash today instead of this stock, would you buy at today's price? If "no," it may be time to sell.

---

## Layer 1: Fundamentals Review (Most Important)

### Moat Status
- [ ] Compared to last year, is the moat **wider, unchanged, or narrower**? (Evidence required — not feelings, data)
- [ ] Market share change? Up __% / Flat / Down __%
- [ ] Gross margin change? Last year ___% → This year ___% (Decline >2 percentage points needs deep analysis)
- [ ] Does pricing power remain? Any discounting/promotions to maintain revenue?
- [ ] New competitive threats? Any compelling competitive product or tech/business model disruption?

### Management Assessment
- [ ] Quality of management decisions this year? (List 2-3 specific major decisions)
- [ ] Did management deliver on stated goals?
- [ ] CEO/management stock ownership changes? (Selling = requires attention)
- [ ] Capital allocation decisions reasonable? (Acquisitions/buybacks/dividends/reinvestment — what results?)
- [ ] Any integrity red flags? (Accounting policy changes? Related-party transaction increases? Auditor changes?)

### Financial Health
- [ ] ROE / ROIC trend? Last year ___% → This year ___%
- [ ] Interest-bearing debt ratio change? Up/Down/Flat; at safe levels?
- [ ] Free cash flow healthy? FCF / Net Income > 80%?
- [ ] Receivables and inventory growth match revenue growth?
- [ ] Any anomalous financial data changes needing deeper investigation?

---

## Layer 2: Valuation Review

### Intrinsic Value Update
- [ ] Based on latest year's data, does my intrinsic value range estimate need adjustment? Upward / Unchanged / Downward. Reason: _________________
- [ ] Where does the current stock price sit relative to my intrinsic value range?
  - Far below lower bound (undervalued) → consider adding
  - Within range → hold
  - Far above upper bound (overvalued) → consider reducing/selling

### Margin of Safety Recalculation
- [ ] At current price, margin of safety is approximately ___%
- [ ] Is this margin comfortable? If studying this stock for the first time today, would I buy at this price?

---

## Layer 3: Thesis Review

### Original Investment Thesis Validation
- [ ] Pull out the "investment memo" written at purchase time (if you didn't write one — start this year)
- [ ] Does the original thesis still hold?
  - ☐ Fully intact — continue holding
  - ☐ Partially intact — reassess
  - ☐ No longer valid — consider selling
- [ ] If original thesis disproven, why haven't I sold? (Be honest — is it "unwilling to admit I was wrong"?)

### Scenario Analysis Update
- [ ] Bull case: if everything goes well, approximate intrinsic value in 3 years?
- [ ] Base case: status quo, approximate intrinsic value in 3 years?
- [ ] Bear case: if worst fears materialize, what could intrinsic value fall to?
- [ ] Does the current price offer an attractive risk/reward ratio?

---

## Layer 4: Portfolio-Level Review

- [ ] How has this holding's portfolio weight changed? (Due to price moves or buying/selling)
- [ ] Does the current weight match my conviction level? (Overweight → reduce / Match → maintain / Underweight → consider adding)
- [ ] Overall portfolio industry concentration? Need adjustment?
- [ ] Do I have sufficient cash reserves?

---

## Layer 5: Behavioral Self-Review

### Past Year Trading Record Review
- [ ] How many buy/sell actions on this stock in the past year?
- [ ] What triggered each action?
  - ☐ Fundamental change (reasonable)
  - ☐ Price movement (caution — are you "predicting the market"?)
  - ☐ Emotion — fear/greed (requires reflection)
- [ ] Reviewing these actions: did they increase or decrease my returns? (Calculate with actual data, not feelings)

### Psychological Review
- [ ] Did I experience anxiety or euphoria from this stock's price swings? (If yes — may not understand it well enough, or position is too large)
- [ ] How much time did I spend "watching the ticker" vs. "researching the company"?
- [ ] Did ownership cause "confirmation bias" (only seeing good news, ignoring bad signals)?

---

## Sell Decision Checklist

**Seriously consider selling** if ANY of these:
- [ ] Moat being eroded, trend appears irreversible
- [ ] Original thesis disproven
- [ ] Better opportunity found (opportunity cost significantly exceeds current holding's expected return)
- [ ] Price far exceeds intrinsic value (negative margin of safety)
- [ ] Need funds for more urgent purposes (this is a planning failure, not an investment judgment)

**Invalid sell reasons** (these should NOT trigger selling):
- Price went down / went up a lot
- Market looks bad
- "Held it long enough"
- Someone else's stock went up more

---

## Annual Investment Memo Template

After completing the above, write a brief annual memo for each holding:

```
[Company Name] Annual Review — 202X

1. Core thesis (one sentence)
2. Most important 1-3 changes this year
3. Moat judgment: Wider / Unchanged / Narrower
4. Intrinsic value range update: ___ to ___
5. Decision: Buy More / Hold / Reduce / Sell
6. Top 1-3 metrics to watch next year

Signed: _________ Date: _________
```
