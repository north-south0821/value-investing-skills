# 巴菲特投资前检查清单

> **"你应该在买入之前做所有的工作，而不是之后。"**
> — Charlie Munger

## 使用说明

本清单应在**每次重大投资决策前**逐项完成。不要跳过任何一项——最容易出问题的永远是"懒得看"的那一条。

每项检查有三个结果：
- ✅ 通过 — 可以进入下一项
- ❌ 不通过 — 排除或等待
- ⚠️ 不确定 — 说明你研究不够，回到学习模式

---

## 第一步：能力圈检查

> 参考：[[../04-circle-of-competence|能力圈]]

- [ ] **我能用三句话解释这家公司怎么赚钱吗？**（写给一个 12 岁孩子也能听懂）
- [ ] **我知道它的主要客户是谁，为什么他们选择它而不是竞争对手？**
- [ ] **我了解这个行业的产业链吗？** 上游是谁？下游是谁？利润在整个产业链中如何分配？
- [ ] **我能预测这家公司十年后的大致模样吗？**
  - 如果答案是"不确定" → 排除
- [ ] **我是否因为"别人都在买"而产生兴趣？**
  - 如果是 → 停下来，搞清楚自己的独立判断

---

## 第二步：护城河检查

> 参考：[[../02-moat-theory|护城河理论]]

### 存在性

- [ ] **这家公司有护城河吗？**（品牌、转换成本、网络效应、成本优势、特许经营——至少一种）
- [ ] **我能否清晰地说出护城河的来源？**（说不出 = 可能不存在）
- [ ] **过去 5 年，毛利率是否稳定或上升？**（下降趋势 = 护城河在变窄）

### 持久性

- [ ] **十年后，这个护城河还会存在吗？**（技术护城河最脆弱，品牌护城河最持久）
- [ ] **有没有一个明显的威胁，在未来 3-5 年可能摧毁这个护城河？**
  - 技术颠覆？
  - 监管变化？
  - 消费者偏好转移？
- [ ] **竞争对手有没有在蚕食它的市场份额？**（看过去 3-5 年的趋势）

### 财务证据

- [ ] **过去 5 年 ROE 持续 > 15%？**（如果是，护城河有财务证据支撑）
- [ ] **经营现金流持续 > 净利润？**（利润质量高）
- [ ] **资本支出 / 净利润 < 50%？**（不需要大量持续投入来维持地位）

---

## 第三步：管理层检查

> 参考：[[../08-buffetts-3M|3M 投资法 — Management]]

### 能力

- [ ] **过去 5 年，管理层承诺的战略目标实现了吗？**
- [ ] **公司在行业中处于什么位置？** 份额在增长还是萎缩？
- [ ] **CEO/创始人是否深度参与经营？**（套现走人的是巨大红旗）

### 诚信

- [ ] **年报中，管理层是否坦诚讨论过错误和挑战？**
  - 如果年报通篇都是"成绩斐然" → 🔴 红旗
- [ ] **会计政策是否保守？**（与同行业对比）
- [ ] **审计师是否稳定？**（频繁更换 = 🔴 红旗）
- [ ] **有关联交易吗？**（如果有，是否有合理的商业理由？）

### 股东导向

- [ ] **CEO 持有多少股份？**（越多越好）
- [ ] **股权激励是否合理？**（稀释速度是否过快？行权条件是否过松？）
- [ ] **留存利润是否创造了至少等值的市值增长？**（一美元前提）

### 资本配置

- [ ] **公司如何处置赚来的利润？**
  - 再投资于主业（最好）
  - 分红（好）
  - 在低估时回购（好）
  - 做收购（小心——大多数收购摧毁价值）
  - 盲目多元化（🔴 红旗）
- [ ] **如果公司做收购，价格合理吗？** 商誉积累了多少？

---

## 第四步：估值与安全边际检查

> 参考：[[../03-margin-of-safety|安全边际]]

### 估算内在价值

- [ ] **我是否估算了一个保守的内在价值区间？**（不是一个精确数字，而是一个范围）
- [ ] **我的假设是否足够保守？**
  - 增长率假设是否低于历史平均水平？
  - 是否考虑了行业周期性的负面影响？
  - 是否考虑了管理层可能出现失误？

### 计算安全边际

- [ ] **当前股价相对我估算的内在价值下沿，折扣有多大？**
  - 30% 以上 → 可以考虑
  - 20-30% → 可以研究，但等待更好价格
  - 小于 20% → 等待（除非是极致优质企业）
- [ ] **如果我的估值错 30%，我还会亏钱吗？**
  - 如果会 → 安全边际不够

---

## 第五步：心理与行为检查

> 这是最重要的检查——你的大脑是你投资中最大的风险源。

### 确认自己不在"情绪模式"

- [ ] **我现在是否处于"害怕错过"（FOMO）状态？**
  - 股价一路上涨，我想"赶紧上车" → ⚠️ 停下来
- [ ] **我现在是否处于恐慌状态？**
  - 市场暴跌，我想"先卖了再说" → ⚠️ 重新审视基本面
- [ ] **我是否因为"大家都在买"而想买？**
  - 如果是 → 这恰恰说明可能需要等待

### 确认自己真正独立判断

- [ ] **我能写出 3 个关于这家公司的负面论点吗？**
  - 写不出来 → 你还没有真正研究清楚
- [ ] **如果有人当面与你辩论，说这是一笔糟糕的投资，你能有理有据地反驳吗？**
  - 不能 → 你的信心可能是盲目自信
- [ ] **如果买入后股价立刻跌了 30%，我的第一反应是"加仓"还是"后悔"？**
  - 如果是"后悔" → 你可能高估了自己对这家公司的理解程度

---

## 第六步：仓位与组合检查

- [ ] **这笔投资占我总资产的比例是否合理？**
  - 单只股票不超过你能承受**永久亏损**的上限（巴菲特建议：想象你的投资组合只有 6 只股票）
- [ ] **我是否使用了杠杆？**
  - 如果是 → 🔴 立即停止。巴菲特和芒格一致反对用杠杆。
- [ ] **这笔投资之后，我还有足够的现金应对生活支出和未来的投资机会吗？**
  - 永远不要 all in——留有"弹药"
- [ ] **我的整个投资组合的行业分散度如何？**
  - 如果某行业出现系统性风险，我的损失在可承受范围吗？

---

## 最终确认

在买入之前，用 500 字以内写下：

1. 我为什么买这家公司？
2. 什么情况下我会卖出？
3. 我预想的持有期是多久？
4. 最坏情况下我会亏多少钱？我能承受吗？

**签名：_____________    日期：_____________**
