# 巴菲特年度复盘清单

> **"每年检视你的持仓，就像你第一次考虑买入它们一样。不要因为已经持有而对它的缺点视而不见。"**
> — 巴菲特的隐含逻辑

## 使用说明

每年至少一次（建议在年底或伯克希尔年报发布后），对每一只持仓使用本清单进行完整复盘。

核心原则：**零基思维**——假设你今天持有的是等额现金，你会用今天的价格买入这只股票吗？如果答案是"不会"，那就是考虑卖出的时候了。

---

## 第一层：基本面复盘（最重要）

### 护城河状况

- [ ] 公司的护城河与去年相比是**加宽了、维持不变还是变窄了**？
  - 具体证据是什么？（不能用感觉，要列举数据）
- [ ] 市场份额变化？
  - 上升 __% / 持平 / 下降 __%
- [ ] 毛利率变化？
  - 去年 ___% → 今年 ___%（下降超过 2 个点需要深入分析原因）
- [ ] 产品的定价能力还在吗？
  - 有没有开始打折促销来维持收入？
- [ ] 有没有新的竞争威胁出现？
  - 竞争对手有没有推出有竞争力的产品？
  - 有没有技术/模式创新可能颠覆这个行业？

### 管理层评估

- [ ] 过去一年，管理层的决策质量如何？（列出具体的 2-3 个重大决策）
- [ ] 管理层承诺的目标完成了吗？
- [ ] CEO/管理层持股变化？（减持 = 需要关注）
- [ ] 资本配置决策是否合理？
  - 收购/回购/分红/再投资——各产生了什么效果？
- [ ] 有任何诚信方面的红旗吗？
  - 会计政策变更？
  - 关联交易增加？
  - 审计师更换？

### 财务健康

- [ ] ROE / ROIC 趋势？
  - 去年 ___% → 今年 ___%
- [ ] 有息负债率变化？
  - 上升/下降/持平；是否在安全水平？
- [ ] 自由现金流是否健康？
  - FCF / 净利润 > 80%？
- [ ] 应收账款和存货的增速是否与营收增速匹配？
- [ ] 有没有任何财务数据的异常变化？（需要深入调查的）

---

## 第二层：估值复盘

### 内在价值更新

- [ ] 基于过去一年的最新数据，我估算的内在价值区间是否需要调整？
  - 上调 / 不变 / 下调
  - 原因：_________________
- [ ] 当前股价在我估算的内在价值区间中处于什么位置？
  - 远低于下沿（低估）→ 考虑加仓
  - 在区间内 → 继续持有
  - 远高于上沿（高估）→ 考虑减仓/卖出

### 安全边际重新计算

- [ ] 以当前股价计算，安全边际约为 ___%
- [ ] 这个安全边际水平让我舒服吗？
  - 如果今天第一次研究这只股票，我会在这个价格买入吗？

---

## 第三层：持有逻辑复盘

### 原始买入逻辑检验

- [ ] 翻出当初买入时写的"投资备忘录"（如果你没写，从今年开始写）
- [ ] 我的原始买入逻辑是否仍然成立？
  - ☐ 完全成立 — 继续持有
  - ☐ 部分成立 — 需要重新评估
  - ☐ 已不成立 — 考虑卖出
- [ ] 如果原始逻辑被证伪，为什么我还没卖？
  - （诚实面对——是否因为"不想认错"？）

### 情景分析更新

- [ ] 乐观情景：如果一切顺利，3 年后的内在价值大概是多少？
- [ ] 中性情景：如果按现状发展，3 年后的内在价值大概是多少？
- [ ] 悲观情景：如果最担心的风险发生，内在价值可能跌到多少？
- [ ] 当前价格是否给我提供了足够好的风险回报比？

---

## 第四层：组合层面复盘

- [ ] 这只持仓在组合中的占比发生了什么变化？（因为涨跌或加仓/减仓）
- [ ] 现在的仓位比例与我对它的信心程度匹配吗？
  - 超配 → 减仓 / 匹配 → 维持 / 低配 → 考虑加仓
- [ ] 整个组合的行业集中度如何？是否需要调整？
- [ ] 我是否有足够的现金储备？

---

## 第五层：自身行为复盘

### 过去一年的交易记录回顾

- [ ] 过去一年我做了多少次买卖这只股票的操作？
- [ ] 每次操作的触发原因是什么？
  - ☐ 基于基本面变化（合理）
  - ☐ 基于价格波动（谨慎——是否在"预测市场"？）
  - ☐ 基于情绪（恐惧/贪婪）（需要反思）
- [ ] 回顾这些操作，它们增加了还是减少了我的回报？
  - （用实际数据计算，不要凭感觉）

### 心理复盘

- [ ] 过去一年，我是否因为这只股票的波动而产生过焦虑/狂喜？
  - 如果有——说明我可能对它不够了解，或者仓位过大
- [ ] 我花了多少时间在"看股价"上？应该花多少时间在"研究公司"上？
- [ ] 我是否因为持有而陷入了"确认偏误"（只看到好消息，忽略坏信号）？

---

## 卖出决策清单

如果满足以下任一条件，**严肃考虑卖出**：

- [ ] 护城河正在被侵蚀，且趋势不可逆
- [ ] 买入时的核心逻辑被证伪
- [ ] 发现更好的投资机会（机会成本大幅超过当前持仓的预期回报）
- [ ] 股价远超内在价值（安全边际为负）
- [ ] 需要资金用于更紧急的用途（这是规划的失误，不是投资的判断）

**不卖的理由**（以下不应触发卖出）：
- 股价跌了 / 涨了很多
- 大盘不好
- 持有时间"够久了"
- 别人的股票涨得更多

## 年度投资备忘录模板

在完成上述检查后，为每只持仓写一份简短的年度备忘录：

```
【公司名称】年度复盘 — 202X

1. 核心持仓逻辑（一句话）
2. 本年度最重要的 1-3 个变化
3. 护城河判断：加宽 / 不变 / 变窄
4. 内在价值估算区间更新：___ 到 ___
5. 决策：买更多 / 持有 / 减少 / 卖出
6. 下一年最关注的 1-3 个指标

签名：_________ 日期：_________
```
